      Why it can be trusted

      Nobody holds the key

      NEAR Chain Signatures signs a pass only after the contract has been paid.

      One machine, one renter

      Each machine has its own key, and one pass at a time.

      Nothing is left behind

      When time is up the session is cut off and the files are wiped.

      How it works, technically

      A pass is a short-lived SSH certificate. Each machine has its own CA key, derived by NEAR Chain Signatures. The contract builds the certificate and requests the signature only after payment. A force-command on the machine ends the session when the time is up.

      Lend out a computer you are not using

      You set the price and withdraw what it earns.

      List a machine

      scripts/host-up.sh <id> <public-host> <price> <port>

      Withdraw what it earned

      bin/gatepass withdraw <machine>

      What renters cannot do

      • Become admin
      • Change the system
      • Reach the internet or your network
      • Stay past their time
      • Leave files behind
